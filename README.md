# 3DA — Craft World

Прототип веб-приложения, где ребёнок фотографирует физическую поделку, а она превращается в 3D-персонажа и появляется в виртуальном мире.

## Текущий этап

Ветка `feat/3d-world-mvp` содержит первый интерактивный прототип:

- Next.js + TypeScript
- React Three Fiber / Three.js
- простая 3D-комната
- тестовый бумажный кот, собранный из примитивов
- движение кота к точке по клику/тапу
- простая процедурная анимация лап и хвоста
- адаптивный интерфейс для телефона и компьютера

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000.

## Roadmap MVP

1. 3D-мир и движение — в работе
2. Камера / загрузка фотографии
3. Backend endpoint для загрузки
4. Image-to-3D API
5. Auto-rig и базовые анимации
6. Оптимизация GLB
7. Сохранение персонажей
8. Коллекция детских поделок

## Продуктовый принцип

Главный эффект должен быть не «AI сделал красивого кота», а «это именно моя поделка, и она ожила».
